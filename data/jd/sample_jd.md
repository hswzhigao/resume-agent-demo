# 招聘 JD（合成示例）：资深 Java 后端工程师（高并发方向）

## 岗位职责

1. 参与核心业务平台的服务端设计与开发，编写单元测试与文档
2. 负责高并发场景下的系统优化：缓存、消息队列、数据库调优
3. 负责系统的日常运行维护、数据监控与报警处理

## 任职要求

1. 扎实的 Java 基础，深入理解并发、集合、JVM
2. 熟练掌握 Spring、Spring Boot 等主流框架，深入理解其实现原理
3. 熟练使用 PostgreSQL 关系型数据库，有数据库建模与 SQL 性能调优经验
4. 具有系统化的排错与调试能力，有线上问题定位经验
5. 有 Redis、Kafka 等中间件使用经验

## 加分项

- 熟悉容器技术（Docker/Podman）与云服务
- 有丰富的单元测试编写经验
- GitHub 有开源项目或技术博客
